# 🎟️ TicketLab

**Tu espacio para crear, personalizar y gestionar tickets de forma sencilla.**

TicketLab es una herramienta diseñada para facilitar la creación de tickets personalizados mediante una interfaz intuitiva, moderna y adaptable a diferentes dispositivos.

## ✨ Características

- 🎫 **Creación de tickets:** diseña y genera tickets personalizados.
- ⚙️ **Perfiles predefinidos:** guarda configuraciones para completar automáticamente determinados campos, además de eliminar, duplicar y editar estos mismos.
- 📝 **Campos personalizables:** introduce y modifica la información de cada ticket.
- 🖨️ **Vista de impresión:** prepara los tickets para imprimirlos.
- 📱 **Diseño responsive:** compatible con ordenadores, móviles y tablets Android.
- 🎨 **Interfaz moderna:** diseño limpio, intuitivo y fácil de utilizar.

## 🚀 Objetivo

El objetivo de TicketLab es ofrecer una solución práctica para crear tickets sin complicaciones, evitando tener que introducir repetidamente la misma información.

## 💻 Compatibilidad

TicketLab está diseñado para funcionar en:

- Windows
- macOS
- Linux
- Android
- Navegadores modernos

## 🛠️ Tecnologías

El proyecto utiliza tecnologías web para ofrecer una experiencia accesible y multiplataforma.

- HTML5
- CSS3
- JavaScript

## 📦 Instalación y uso

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Empieza a crear y personalizar tus tickets.

No necesitas instalar programas adicionales.

## 🔒 Privacidad

TicketLab está pensado para ofrecer una experiencia sencilla y privada. No introduzcas información personal o confidencial en tickets que puedan compartirse públicamente.
